# RL Maze Explorer 웹 학습

최신 Chrome 또는 Edge에서 `index.html`을 엽니다. GitHub에서 직접 내려받으려면 이 브랜치의 **Code → Download ZIP**을 누른 뒤 압축을 풉니다. HTTPS 정적 호스팅에서도 같은 파일을 사용할 수 있습니다. 모델 계산은 페이지를 연 PC의 브라우저에서 수행합니다.

1. **학습 환경 준비**를 누르면 브라우저가 학습용 작업 스레드를 시작합니다.
2. 기본 설정은 64×64, 100,000스텝, 귀환 연습 30%입니다. **새 학습** 또는 **이어 학습**을 선택합니다.
3. **저장 후 정지**는 현재 학습 묶음이 끝난 뒤 모델을 저장합니다. **모델 다운로드**로 JSON을 백업할 수 있습니다. 브라우저 저장이 허용되면 같은 페이지를 다시 열고 환경 준비를 눌러 최근 체크포인트를 복원할 수 있습니다. 학습 중에는 탭을 열어 두세요.

## GitHub

- **GitHub 모델 목록**에서 기존 `models` 브랜치의 v3 모델 ZIP과 웹 체크포인트, v3 Releases를 선택할 수 있습니다. Release 서버가 직접 읽기를 허용하지 않으면 화면에 표시된 링크로 ZIP을 받은 뒤 **모델 불러오기**로 엽니다.
- 업로드에는 이 저장소의 **Contents 읽기·쓰기** 권한이 있는 GitHub 토큰이 필요합니다. 토큰은 페이지의 비밀번호 입력칸에서만 사용합니다. **GitHub에 모델 저장**을 누르거나 학습 완료·중지 시 자동 업로드를 켭니다.
- 웹 모델은 `models` 브랜치의 `browser-checkpoints/`에 압축 JSON으로 저장합니다. Python에서 이용하는 기존 ZIP이나 Releases는 별도로 유지됩니다. 업로드가 실패하면 브라우저에 남은 모델을 다운로드하거나 다시 올릴 수 있습니다.

## 모델 호환 범위

기존 v3의 관측 공간, 학습 보상·정체 종료, 충전 조건을 웹 코드에 옮겼습니다. 브라우저와 Python의 난수 생성기 및 부동소수점 연산 차이로 결과가 스텝 단위로 동일하다고 볼 수 없습니다.

기존 v3 SB3 ZIP에서는 지원하는 PyTorch 텐서 형식의 가중치와 Adam 상태를 읽습니다. Adam 상태를 읽지 못하면 가중치와 누적 스텝을 불러오고 옵티마이저는 초기화하며 화면에 표시합니다. 웹 체크포인트는 웹 학습기에서 이어 학습할 수 있습니다.

검증은 브라우저 작업 스레드와 같은 JavaScript 학습 코드를 Node 작업 스레드에서 실행하여 새 학습, 테스트용 SB3 형식 ZIP 가져오기, Adam 상태를 포함한 이어 학습, 저장 후 정지를 확인했습니다. GitHub API 요청 흐름은 모의 응답으로 확인했습니다. GitHub 사용자의 권한을 사용하는 실제 업로드 및 기존 저장소 모델 ZIP 가져오기는 아직 확인하지 않았습니다.
