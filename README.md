# RL-Maze-Explorer

## BAT 없이 브라우저에서 로컬 학습

Windows용 `RL-Maze-Explorer-Web-Windows.zip` 전체를 풀고 `RL-Maze-Explorer.exe`를 실행하면 브라우저에서 환경 준비, 크기별 새 학습·이어 학습, 모델 저장 후 중지를 사용할 수 있습니다. 계산은 해당 컴퓨터에서 수행합니다. 사용 방법은 [docs/DESKTOP.md](docs/DESKTOP.md)에 있습니다.

현재 기본 학습은 **64×64 v3**입니다. 가까운 3칸의 교차로 정보와 먼 직선 통로 길이를 구분하고, 충전은 2턴입니다.
기존 v1/v2 모델은 보존하고 새 입력 구조로 학습합니다.
`ppo_v3_model_summary.txt`로 학습 요약을 확인하고, `evaluate_ppo.bat`로 별도 평가 결과를 저장합니다.
최신 실행 방법·조건·검증: [docs/TRAINING_V3.md](docs/TRAINING_V3.md).

강화학습 기반 동적 환경 적응형 의사결정 모델 개발 — 인공지능응용 과제

## 현재 구현
- 기본 **64×64** DFS/Prim 미로. 서로 다른 외곽 변의 무작위 시작점·출구, 모서리 제외.
- BFS 경로 길이 하한 검사(기본 size칸), 연결성 검사, 기존 벽 추가 검증 함수.
- 전진/좌회전/우회전 각 1턴. 에너지 1 / 0.5 / 0.5.
- 방향별 시야, 벽 차폐, 미관측/통로/벽/출구/충전소 기억 지도.
- 시작점 반복 충전 및 기억 유지.
- 방향을 포함한 최소 턴 경로 계산. 동일 턴이면 에너지가 적은 경로 선택.
- 수동 조작 데스크톱 화면: 전체 지도와 관측·기억 지도, 배터리·턴·충전 표시.
- Gymnasium 연결 및 공개 PPO 학습·저장·이어 학습 스크립트.
- 44개 자동 테스트 (학습 테스트에는 requirements-rl.txt 설치 필요).

**PPO 연결과 짧은 학습 테스트를 완료했습니다.**
`train_ppo.bat`: GitHub 저장/이어 학습, `watch_ppo.bat`: 모델 재생, `sync_ppo.bat`: 미전송 백업 업로드.
주 저장소는 GitHub Releases이며 루트의 ppo_v3_model.zip은 로컬 백업입니다. 직접 학습하는 방법과 검증 기록은
[docs/TRAINING.md](docs/TRAINING.md)를 참고하십시오. 탈출 성능 검증, 브라우저 추론 및 웹 편집 화면은 후속 작업입니다.

## 실행 (Python 3.10 이상)

이 단계는 외부 패키지가 필요 없습니다. GUI는 Python 설치 시 Tcl/Tk가 포함되어 있어야 합니다.

```bash
python -m environment.demo
python -m environment.demo --size 16 --algorithm prim --seed 7
python -m environment.demo --size 64 --battery-margin 1.5 --charge-turns 10
python -m environment.demo --headless
python -m unittest discover -s tests -p test_maze.py -v
python -m unittest discover -s tests -p test_robot.py -v
python -m environment.maze_generator --size 64 --algorithm prim --seed 7 --quiet
```

Windows에서는 `start_demo.bat`를 더블클릭합니다(Python Launcher `py` 필요).
화면: 방향키 ↑ 전진, ← 좌회전, → 우회전, C 충전, R 같은 미로 초기화.
이동과 회전은 별도 행동입니다. ↑는 화면 위가 아니라 로봇이 바라보는 방향으로 전진합니다.
충전은 시작점에서만 가능합니다. 초록=출구, 노랑=시작점 충전소, 빨강=로봇,
오른쪽 회색=미관측, 파랑 계열 통로=현재 시야입니다.

## 확정 규칙과 임시 설정

확정: 64×64, 부분 관측, 시작점 무제한 반복 충전, 충전 후 기억 유지, 출구 도달 목표,
전진 에너지 1, 회전 0.5, 각 1턴. 초기 방향은 이 구현에서 미로 안쪽으로 지정합니다.

아래는 실행 가능한 기반을 위한 **임시값**이며 사용자가 확정한 실험 수치가 아닙니다.

| 항목 | 기본값 |
|---|---|
| 배터리 용량 | 최소 턴 경로의 에너지 × 1.25, 0.5 단위 올림 |
| 시야 | 전방 3칸 좌우 연결, 4칸부터 직선 거리만, 벽 뒤 차단 |
| 충전 | 별도 행동 3, 2턴 후 완충, 횟수 무제한 |
| 충돌 | 1턴 및 에너지 1 소모 |
| 최대 턴 | 20,000 |
| 보상 | 턴 -0.01, 신규 관측 칸 +0.01, 충돌 -0.05, 탈출 +10, 소진 -1 |

학습 v3의 보상과 연습 상황은 docs/TRAINING_V3.md가 기준입니다. 위 보상 표는 초기 RobotEnv의 참고값입니다.
`environment.robot.Config`는 이전 버전 호환을 위해 기본 충전 5턴을 유지하지만 v3 학습과 수동 데모에서는 2턴을 명시합니다. 배터리 부족으로 행동을 수행할 수 없으면 실패합니다.
정확히 0으로 출구에 도달하면 성공, 시작점에 도달하면 충전 가능, 다른 위치면 소진 실패입니다.
완충 상태 또는 충전소 밖에서 충전 시도 시 1턴과 임시 페널티만 적용합니다.
남은 시간보다 완충 시간이 길면 충전 완료 없이 턴 제한으로 종료됩니다.

## 정보 분리

정책 입력은 `RobotEnv.observation()`만 사용합니다. 전체 미로, 출구 좌표, 최단경로는
`maze`, `minimum_turn_route`, `debug_stats()` 등 환경·평가자 전용이며 정책 입력으로 넘기지 않습니다.
관측의 위치·방향은 정확한 행동 결과에 따른 위치 추정(위치 오차가 없는 시뮬레이션)을 가정합니다.
관측은 복사본이어서 정책이 반환된 지도를 수정해도 환경 기억을 바꾸지 않습니다.

**설계상 한계:** 배터리 용량이 출구까지의 기준 경로에서 산출되므로 용량 자체가 경로 비용에 대한
간접 정보를 포함합니다. 출구 좌표를 공개하는 것은 아니지만 완전한 독립 정보는 아닙니다.
또한 한 번에 탈출 가능한 용량이 미지의 영역을 안전하게 왕복 탐색할 수 있음을 보장하지 않습니다.

## 새 Windows 컴퓨터에서 한 번에 준비

전체 프로젝트 ZIP을 다운로드해 압축을 풀고 `setup_windows.bat`를 실행합니다.
Python 3.12(64비트), 가상환경, CPU용 PyTorch 및 학습 패키지, GitHub CLI를 준비하고 자동 검사를 실행합니다.
Python이 없으면 공식 Python 3.12.10 Windows 설치 파일을 사용합니다. 기존 3.12.7 등 호환 설치는 재사용합니다.
GitHub 계정의 브라우저 로그인은 직접 한 번 완료해야 합니다. 로그인하지 못해도 설치된 프로그램은 유지되며, 다음 학습 실행에서 다시 로그인할 수 있습니다.
준비가 끝나면 `train_ppo.bat`를 실행하고 1번을 선택해 GitHub의 최신 v3 모델부터 이어 학습합니다.

- 지원 대상: Windows 10/11, Intel/AMD 64비트 PC, 인터넷 연결
- 이 BAT는 프로젝트 전체 폴더와 함께 사용합니다. BAT 파일만 복사해서는 사용할 수 없습니다.
- Git/VS Code/Anaconda를 별도로 설치할 필요는 없습니다. GitHub CLI는 필요할 때 `.tools`에 준비합니다.
- GPU 설치는 하지 않으며 다른 PC에서도 동일하게 실행하기 위해 CPU 환경을 준비합니다.
- 다른 PC에서 복사한 가상환경이 작동하지 않으면 이름을 바꿔 보존한 뒤 새 환경을 만듭니다.
- 기존 학습 모델과 기록은 삭제하거나 덮어쓰지 않습니다. 설치 중 본 학습이나 업로드를 실행하지 않습니다.
- 설치 오류는 `setup_windows.log`에 기록합니다. 계정 로그인 과정은 이 로그에 기록하지 않습니다.
- 학교/회사 PC에서 설치나 PowerShell 실행이 정책으로 차단되어 있으면 관리자 도움이 필요합니다.
- 현재 확인 범위는 아래 개발 검증 기록을 참고하세요. 새 Windows PC의 실제 설치는 별도 확인이 필요합니다.

개발 검증: 기존 Python 자동 검사 44개 통과. PowerShell 7에서 설치 스크립트 구문 검사와 명령 성공/실패 처리 검사를 통과했습니다. Windows PowerShell 5.1 문법으로 작성했으나 실제 Windows 신규 설치·브라우저 인증은 현재 환경에서 실행하지 못했습니다.
