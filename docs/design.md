# 설계 및 기반 구현 (2026-10-24)

## 목적과 범위
제한된 정보·자원으로 미로를 탈출하는 로봇을 학습하고 학습 단계별 행동을 비교한다.
현재는 환경 기반 구현이며 학습 실험 전 단계다. 보고서 제목은
“강화학습 기반 동적 환경 적응형 의사결정 모델 개발”을 유지한다.
한 실행의 미로 지형과 시작점 충전소는 기본적으로 고정된다.

## 미로
64×64 기본. 작은 미로 디버깅 가능. DFS/Prim 생성 후 다른 변에 출발점·출구를 무작위 배치한다.
모서리를 제외하고 내부 통로로 연결한다. 짝수 크기의 남는 벽층에도 연결 통로를 연다.
기본 최소 이동 경로 길이는 size칸이며 생성기 인자로 조정한다.
512회 후보 배치 실패 시 명시적 오류를 반환한다. 무한 재생성하지 않는다.
출발점 방향은 안쪽. 에너지 기준은 (좌표,방향) 공간에서 최소 턴을 먼저, 같은 턴이면 에너지를 최소화한다.

## 행동·자원
0 전진, 1 좌회전, 2 우회전, 3 충전. 충전은 기반 구현을 위한 추가 명시적 행동이다.
전진/회전은 1턴, 에너지는 1/0.5. 충돌 비용, 충전 시간, 보상, 턴 제한은 임시 설정값이다.
에너지는 내부에서 0.5단위 정수로 관리한다. 초기 용량은 기준 에너지 × battery_margin을 올림한다.
충전은 시작점에서만 1회 charge_turns를 소모한 뒤 완충한다. 기억을 지우지 않는다.
보상은 신규 관측 시 한 번만 지급하며 충전 자체에는 양의 보상을 주지 않는다.

## 부분 관측
시야는 앞쪽 90도 원뿔과 거리 제한이다. 격자 supercover ray로 벽 차폐와 대각선 틈새 통과를 막는다.
벽 표면은 보이고 뒤는 보이지 않는다. 시작점은 처음부터 기억한다.
지도 코드: -1 미관측, 0 통로, 1 벽, 2 발견한 출구, 3 충전소.
현재 관측/기억과 정확한 이동 결과 기반 위치·방향, 잔량·용량을 반환한다.
초기 시야에 출구가 실제로 들어오면 관측 가능하다. 미관측 출구 위치는 제공하지 않는다.
각 reset에서 기억을 초기화하고 입력 Maze도 복사한다.

## 정보 누출과 물리적 제약
정책은 observation()만 사용한다. oracle/전체 지도/성능 통계는 평가자 전용이다.
용량을 숨겨진 최단경로에서 산출한다는 사용자의 설정은 경로 비용의 간접 단서를 포함한다.
충전소 하나와 작은 배터리만으로 모든 미지의 미로를 안전하게 탐색할 수 있다는 보장은 없다.
실험 시 이 제약을 결과 해석에 포함하고, 여유분을 임의로 성공률에 맞춰 평가 도중 변경하지 않는다.

## 검증과 다음 단계
수동 데모로 관측·충전을 확인한다. GUI에서 표시하는 전체 지도는 사용자 전용이다.
후속: Gymnasium 공간 정의 → 작은 미로 PPO 학습 → 고정 체크포인트 비교 → ONNX/웹 추론 검증.
학습·검증·최종 평가용 시드를 분리하고 동일 조건에서 모델들을 비교한다.
성공률, 턴, 실패 원인, 충전 시점과 잔량, 충돌, 궤적을 기록한다.
