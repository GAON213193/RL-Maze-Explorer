# 설계 초안 (2026-10-19)

## 학습 / 테스트 구분
- 학습: 다양한 절차 생성 미로, Python 시뮬레이터, 가중치 업데이트 허용
- 테스트: 처음 보는 미로, 고정된 모델 가중치, 추론 및 일시적 탐색 기억 갱신만 허용
- 전체 지도·출구·BFS 최단 경로는 환경/편집기/평가자 전용 정보

## 부분 관측
초기 정보: 미로 크기, 위치, 방향, 이동 규칙.
관찰: 방향별 시야 및 벽 차폐. 출구 위치는 시야에 들어와야 알 수 있다.
탐색 기억: 미관측 / 통로 / 벽 / 발견한 출구. 변경된 벽은 실제 관찰 후에만 갱신.

## 행동
0: 전진, 1: 왼쪽 회전, 2: 오른쪽 회전. 각 1턴.
전진 충돌은 제자리 유지 및 페널티.

## 보상·종료 후보 (아직 실험 전)
- 새로운 칸 관찰: 소량의 탐색 보상
- 출구 발견: 추가 보상
- 출구 도달: 큰 성공 보상 및 종료
- 턴 소모, 벽 충돌: 작은 페널티
- 반복/탐색 정체: 선택적 페널티 및 에피소드 종료
- 되돌아가기는 정상적인 탐색 행동이므로 무조건 실패 처리하지 않음
- 최대 턴 제한: 미로 크기에 맞춰 설정

## 모델·실험
- PPO를 첫 후보로 사용. 관찰 및 기억 인코딩 방식은 구현 후 검증.
- 학습 데이터와 평가 데이터는 서로 다른 시드 및 미로로 분리.
- 비교 후보: 탐색 보상 유무, 정체 종료 유무, 기억 입력 유무.
- 지표: 탈출 성공률, 평균 턴, 탐색률, 반복 방문, BFS 최단 경로 대비 효율.
- 32×32/64×64의 높은 성공률은 보장되지 않으며 실제 실험으로 검증.

## 웹 (후속)
좌측 전체 미로/경로/시야/이동 흔적, 우측 에이전트가 기억하는 지도.
재생 속도, 정지/한 턴 실행, 미로 편집.
벽 추가 시 현재 에이전트 위치에서 출구까지 BFS 경로가 남는지 검증.
실행 도중 편집 시 녹화 재생이 아닌 실시간 추론을 수행.
