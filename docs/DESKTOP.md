# 브라우저에서 로컬 학습 실행

Windows 10/11 Intel·AMD 64비트 컴퓨터용입니다.

1. ZIP 전체를 다운로드하고 문서 폴더 등 쓰기 가능한 위치에 압축을 풉니다.
2. RL-Maze-Explorer.exe를 실행합니다. runtime 폴더를 함께 보관하세요.
3. 브라우저가 열리면 「학습 환경 준비」를 누릅니다. 처음에는 학습 패키지를 다운로드하므로 인터넷 연결과 충분한 디스크 공간이 필요합니다.
4. 미로 크기와 학습량을 선택하고 「새 학습」을 누릅니다.
5. 같은 모델을 이어 학습하려면 로컬 모델 목록에서 선택하고 「이어 학습」을 누릅니다. 다른 크기에서도 이전 가중치를 사용할 수 있습니다.
6. 학습을 멈추려면 「저장하고 학습 중지」를 누릅니다. 저장이 끝나고 완료가 표시될 때까지 기다립니다.
7. 작업을 마친 뒤 「실행 프로그램 종료」를 누릅니다.

학습과 모델 저장은 이 컴퓨터에서 수행합니다. 모델과 CSV·TXT 기록은 압축을 푼 폴더의 runs 아래에 저장됩니다. 브라우저 탭을 닫아도 학습은 계속됩니다. 다시 켤 화면은 .launcher/open-browser.url에 있습니다.

기존 runs 폴더를 이 폴더에 복사하면 v3 모델이 로컬 목록에 표시됩니다. 기존 모델은 선택한 크기와 다른 크기에서도 이어 학습할 수 있습니다. 각 실행은 새로운 폴더에 저장됩니다.

GitHub 백업을 사용하려면 「GitHub 로그인」을 누르고 기록에 표시된 코드를 브라우저에 입력합니다. 이후 「GitHub에서 이어받고 학습 기록도 자동 업로드」를 켭니다. 이 옵션의 이어 학습은 크기와 관계없이 GitHub의 최신 v3 체크포인트를 선택합니다. 업로드 실패 시 로컬 모델을 보존합니다.

GitHub 로그인만 진행 중일 때 취소하려면 콘솔이 없으므로 Windows 작업 관리자에서 해당 gh.exe를 종료할 수 있습니다. 학습은 화면의 저장 후 중지 기능을 사용하세요.

Windows의 일반 프로그램 실행 권한이 필요합니다. 기기 관리 정책이나 보안 프로그램이 실행을 차단하는 경우 관리자에게 실행 허용을 요청하세요. 이 프로그램은 정책 변경이나 관리자 권한 상승을 수행하지 않습니다.

학습 환경 준비는 압축 안의 전용 Python에 패키지를 설치합니다. 시스템에 Python을 별도로 설치하지 않습니다. 기본 학습 장치는 CPU입니다.

개발 검증은 로컬 HTTP 요청 검증, 학습 저장·중지·이어 학습 및 기존 자동 검사를 포함합니다. Windows 실기기에서 EXE 더블클릭부터 설치·학습까지의 전체 과정은 별도 확인이 필요합니다.
