# 탐색 학습 v2 — 2026-10-25

기존 80,896스텝 모델은 완료된 60판 모두 배터리 부족으로 종료했습니다.
세 평가 미로의 512행동 관찰에서도 회전만 반복했습니다. 기존 GitHub 릴리스 및 로컬 파일은 보존합니다.

## 바로 실행

최신 프로젝트 파일을 기존 프로젝트 폴더에 덮어써서 `.venv`, `runs`, 기존 모델은 유지합니다.
`train_ppo.bat`를 실행하고 **1**을 선택합니다.
GitHub에서 `ppo-v2-` 모델만 검색하므로 첫 실행은 기존 실패 모델을 이어받지 않고 새로 시작합니다.
기존 `ppo-run-` 체크포인트는 삭제되지 않으며 자동 이어 학습 대상에서만 제외됩니다.
원격 조회가 실패하면 새 모델로 시작하지 않고 오류로 중단합니다.

- **1**: 최신 v2 이어 학습, 없으면 7×7 새 학습
- **2**: 독립적인 7×7 v2 새 모델
- **3**: v2 가중치를 유지하며 크기 선택: 7 / 11 / 17 / 33 / 64

첫 단계는 7×7이며 최종 과제 목표는 64×64입니다. 자동으로 난이도가 올라가지는 않습니다.
각 단계에서 탈출과 탐색 행동을 평가한 뒤 3번으로 다음 크기를 선택합니다.
한 번 실행할 때 추가 10만 스텝입니다. GPU 사용 설정은 변경하지 않았으며 기본 CPU입니다.
GitHub 우선 저장, 로컬 백업, 실패 시 재전송 동작은 유지합니다.
로컬 최신 백업 이름은 `ppo_v2_model.zip`과 `ppo_v2_model.json`입니다.
`watch_ppo.bat`는 v2 모델을 표시합니다. 기존 모델은 CLI에서 --local --model 기존모델.zip으로
설정 JSON과 함께 불러올 수 있습니다. 기존 환경은 legacy-v1로 복원합니다.

## 바뀐 규칙

이동/회전의 시간 및 에너지 비용과 시작점 충전은 유지합니다. 보상만 v2 환경에서 별도로 계산합니다.
기존 RobotEnv 보상은 v2에서 사용하지 않습니다.

| 항목 | v2 보상/처리 |
|---|---|
| 시간 비용 | 소모 턴당 -0.002 |
| 처음 실제로 밟은 칸 | +0.05, 판마다 한 번 (충전해도 초기화하지 않음) |
| 벽 충돌 | 추가 -0.02 |
| 연속 회전 | 첫 두 번은 시간 비용만, 세 번째부터 매번 추가 -0.02 |
| 불필요한 충전 시도 | 추가 -0.02 |
| 탈출 | +10 |
| 배터리 부족/턴 제한 | -2 |
| 24행동 연속 위치 변화 없음 | -2 후 해당 판 중단 (`stalled`) |

24행동 중단은 학습을 위한 인위적 제한이며 최종 평가 조건과 구분해야 합니다.
이 제한은 이동을 강제로 선택하거나 출구를 알려주는 규칙이 아닙니다.
벽 충돌, 앞뒤 왕복 등 다른 반복 행동 가능성도 있으므로 행동 통계를 계속 확인합니다.

## 관측과 난이도

미로 크기에 따라 입력층을 바꾸지 않도록 9×9 자기 방향 기준 주변 기억 지도를 사용합니다.
관측한 지형 5종, 현재 시야, 실제 방문 여부와 위치/시작점/방향/배터리/회전 누적 등을 입력합니다.
숨겨진 출구 좌표·전체 실제 미로·최단경로는 입력하지 않습니다.
시뮬레이터는 전체 관측 기억을 유지하지만, v2 정책은 그중 현재 위치 주변 9×9만 읽습니다.
따라서 멀리 있는 탐색 기억을 직접 조회하는 능력에는 한계가 있습니다.
이 구조는 7×7에서 학습한 가중치를 11×11 이상에도 그대로 불러올 수 있습니다.
초기 배터리 용량 산식의 간접 정보 한계는 기존과 같습니다.

metrics.json과 episodes.csv에 제자리 중단, 실제 이동, 방문 칸을 추가했습니다.
`action_counts` 순서는 전진/좌회전/우회전/충전입니다. 통계는 이번 실행에서 완료된 판 기준입니다.
환경 설정에 기록된 legacy 보상 필드보다 `profile: exploration-v2`의 위 규칙이 우선합니다.

## 실제 소규모 검증

Linux CPU, seed=42, v2 7×7, 20,096스텝 학습:
- 학습 중 733판 종료, 17회 탈출, 최근 100판 성공률 7%
- 별도 평가 시드 10000~10029 (30판), 학습 중 갱신 없음

| 조건 | 결정적 성공 | 평균 실제 이동 | 평균 방문 칸 |
|---|---:|---:|---:|
| 동일 v2 구조, 학습 전 | 0/30 | 0 | 1 |
| 20,096스텝 학습 후 | 2/30 | 10.07 | 9.70 |

확률적 행동 평가: 학습 전 0/30, 학습 후 1/30 성공.
작은 미로 한 학습 시드에서의 초기 점검입니다. 충분한 탈출 성능이나 64×64 일반화를 입증하지 않습니다.
기존 모델의 64×64 결과와 직접적인 성능 비교를 하지 않습니다.
실험 모델을 기본 모델로 배포하지 않으며 사용자 새 학습은 무작위 가중치부터 시작합니다.
평가 원본 결과는 docs/v2_pilot_results.json에 있습니다.

평가 실행 예:
```
python -m training.evaluate --run runs/실행폴더 --episodes 30 --seed 10000
```
크기를 높일지 여러 번 판단할 때는 추가 평가 시드도 사용해야 합니다.

자동 검사: 기존 테스트 및 보상·관측·버전 격리 등 총 32개 통과.
7→11 크기 변경 후 이어 학습/주기 저장/루트 백업 및 화면 없는 재생도 확인했습니다.
Windows BAT/GUI의 이번 수정본은 이 환경에서 직접 실행하지 못했습니다.
